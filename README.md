# LP Summit Philadelphia 2026, event guide

Great Wave Ventures LP Summit, October 19 to 22, 2026. Live at https://summit.greatwave.vc

- `index.html` is the whole guide (content, schedule, styles, logos embedded). It is generated from `LP_Summit_Guide_Content_vN.json`; edit the content file and rebuild rather than hand-editing the HTML.
- `manifest.webmanifest`, `sw.js` and the icons make it installable from the phone's home screen and readable offline.
- `CNAME` holds the custom domain. Do not delete it.
